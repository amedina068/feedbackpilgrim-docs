# Support

This page tells you where to get help with Feedback Pilgrim and with its documentation.

## Read the documentation

The published documentation is at [feedbackpilgrim.com/docs](https://feedbackpilgrim.com/docs). This repository holds the source of those pages.

## Ask a question

Ask questions in the [Q&A category of the discussions](https://github.com/amedina068/feedbackpilgrim/discussions/categories/q-a) of the app repository. Search the existing discussions before you start a new one.

Do not open an issue for a question. The issues of this repository are for errors in the docs and for missing pages.

## Report a problem

- If a page is not correct, open an issue with the "Error in the docs" form.
- If the docs do not explain a feature, open an issue with the "Missing information" form.
- If the app has a bug, open an issue in the [app repository](https://github.com/amedina068/feedbackpilgrim/issues).

## Report a security problem

Do not report a security problem in an issue or a discussion. Read [SECURITY.md](SECURITY.md) and report the problem in private.

## Response time

One person maintains this project, so answers are not immediate. The maintainer reads each question, but a reply can take some days.
