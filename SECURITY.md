# Security policy

## A security problem in Feedback Pilgrim

This repository holds only the documentation. Report a security problem in the Feedback Pilgrim app in the app repository:

- Read the [security policy of the app](https://github.com/amedina068/feedbackpilgrim/blob/main/SECURITY.md).
- Report the problem in private with the [advisory form of the app](https://github.com/amedina068/feedbackpilgrim/security/advisories/new).

Do not open a public issue, a discussion or a pull request for a security problem.

## A security problem in the docs site

You can report a problem in the docs site itself in private in this repository. Examples are a script injection in a page or a link to a harmful site.

1. Open the **Security** tab of this repository.
2. Click **Report a vulnerability**.
3. Fill in the form and submit it.

A wrong instruction in a page that makes an install unsafe is also a security problem. For example, a page that tells you to expose a secret. Report it in private in the same way.

## What happens next

One person maintains this project, so answers are not immediate. The maintainer reads each report and replies in the advisory.
